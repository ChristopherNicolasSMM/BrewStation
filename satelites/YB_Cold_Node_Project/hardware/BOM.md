# Bill of Materials (BOM)

- ESP32 DevKit
- DS18B20 Temperature Sensor x1 ou x2
- resistor 4.7k para pull-up do OneWire
- módulo de relé 1 canal, acionável em 3.3V, carga máxima conforme sua aplicação
- LCD 16x2 Keypad / HD44780 fundo azul
- buzzer (opcional)
- LED indicador (opcional)
- fonte DC estável para a eletrônica
- caixa / enclosure
- bornes, fios e conectores
