## O Guia Completo: Seu Servidor Debian 13 com Acesso Web

Este guia vai transformar seu computador antigo em um servidor acessível de qualquer lugar pelo navegador do celular, sem precisar instalar nada no cliente e sem abrir portas no roteador.

### 📋 O que você vai precisar

- Um computador antigo para servir como servidor.
- Um **domínio próprio** (pode ser comprado por valores baixos em sites como Registro.br, Namecheap ou Porkbun). A Cloudflare exige um domínio próprio para configurar os túneis gratuitos de forma segura.
- Uma conta gratuita no site da [Cloudflare](https://www.cloudflare.com).


### Passo 1: Instalando o Debian 13.4.0 Trixie

A versão estável mais recente do Debian é a 13.4, codinome "Trixie".

1.  **Baixe a ISO**: Acesse o site oficial do Debian e baixe a imagem de instalação para a arquitetura do seu computador (provavelmente amd64).
2.  **Crie um pendrive bootável**: Use um programa como o **Rufus** (no Windows) ou o comando `dd` (no Linux) para gravar a ISO no pendrive.
3.  **Inicie a instalação**: Insira o pendrive no computador antigo, ligue-o e entre no menu de boot (geralmente pressionando F12, F2 ou Del). Selecione o pendrive para iniciar a instalação.
4.  **Siga o assistente**: O instalador do Debian é bem intuitivo. Nas opções de software, escolha **"Servidor padrão"** ou **"Servidor web"** para manter o sistema enxuto e sem interface gráfica. Isso garante que ele rode bem, mesmo em hardware mais modesto.
5.  **Configuração inicial**: Crie um usuário para você (com privilégios `sudo` através do grupo `sudo`) e defina uma senha forte para o usuário `root`. Para uma instalação mínima, o Debian 13 roda com menos de 100 MB de RAM.


### Passo 2: Configurando o Sistema e Instalando o Python 3.13.3

Agora que o Debian está instalado, vamos preparar o ambiente.

1.  **Acesse o terminal**: Faça login com o seu usuário. Como não há interface gráfica, você estará diretamente no terminal.

2.  **Atualize o sistema**: Mantenha seu sistema sempre atualizado.
    ```bash
    sudo apt update && sudo apt upgrade -y
    ```

3.  **Instale o servidor SSH**: O OpenSSH é essencial para o Cloudflare Tunnel.
    ```bash
    sudo apt install openssh-server -y
    sudo systemctl enable --now ssh
    ```

4.  **Instale o Python 3.13.3**:
    A versão 3.13.3 não está nos repositórios padrão do Debian 13, que por padrão oferece versões como a 3.11 ou 3.12. Para instalar a versão específica, precisamos compilar a partir do código-fonte.

    Primeiro, instale as dependências de compilação:
    ```bash
    sudo apt install -y build-essential libffi-dev libssl-dev zlib1g-dev libbz2-dev libreadline-dev libsqlite3-dev lzma liblzma-dev
    ```
    Agora, baixe o código-fonte da versão 3.13.3 do site oficial e compile-a. Este processo pode levar alguns minutos.
    ```bash
    cd /tmp
    wget https://www.python.org/ftp/python/3.13.3/Python-3.13.3.tgz
    tar -xzf Python-3.13.3.tgz
    cd Python-3.13.3
    ./configure --enable-optimizations
    make -j $(nproc)  # Use todos os núcleos do processador para acelerar
    sudo make altinstall
    ```
    O `make altinstall` é usado para não sobrescrever o comando `python3` padrão do sistema. O novo executável ficará disponível como `python3.13`.

5.  **Verifique a instalação**:
    ```bash
    python3.13 --version
    ```
    A saída deve ser `Python 3.13.3`.

6.  **(Opcional) Crie um link simbólico**: Para usar `python3` e `pip` apontando para a nova versão, você pode usar o `update-alternatives`.
    ```bash
    # Adiciona o Python 3.13 como uma alternativa
    sudo update-alternatives --install /usr/bin/python3 python3 /usr/local/bin/python3.13 1
    # Se houver outras versões, use o comando abaixo para escolher qual será a padrão
    sudo update-alternatives --config python3
    ```


### Passo 3: Preparando e Executando o Projeto (Aplicativo Exemplo)

Como o repositório `github.com/ChristopherNicolasSMM/BrewStation` parece não estar público, este guia usa um aplicativo de demonstração simples. Você pode adaptar estes passos para implantar seu próprio projeto.

1.  **Crie um diretório para o projeto**.
    ```bash
    mkdir ~/meu_app
    cd ~/meu_app
    ```

2.  **Crie um ambiente virtual**: Isto isola as dependências do seu projeto do resto do sistema.
    ```bash
    python3.13 -m venv venv
    source venv/bin/activate
    ```

3.  **Crie um aplicativo web simples**: Vamos criar um arquivo `app.py` com um servidor HTTP básico.
    ```bash
    nano app.py
    ```

    Cole o seguinte código:
    ```python
    import http.server
    import socketserver

    PORT = 8080
    Handler = http.server.SimpleHTTPRequestHandler

    with socketserver.TCPServer(("", PORT), Handler) as httpd:
        print(f"Servidor rodando na porta {PORT}")
        httpd.serve_forever()
    ```

    Salve o arquivo (Ctrl+O, Enter) e saia (Ctrl+X).

4.  **Execute o aplicativo**: Com o ambiente virtual ativado, inicie o servidor.
    ```bash
    python app.py
    ```

    Para testar localmente, abra outro terminal e use o `curl`:
    ```bash
    curl http://localhost:8080
    ```
    Você verá o conteúdo do diretório. O servidor está funcionando! Interrompa-o com `Ctrl+C`.

    Para deixá-lo rodando em segundo plano, podemos usar o `screen` ou `tmux`, ou criar um serviço `systemd`. Para este guia, vamos usar um método simples com o `nohup`.
    ```bash
    nohup python app.py > app.log 2>&1 &
    ```

    **Importante**: Lembre-se da porta que seu aplicativo está usando (no exemplo, é a **8080**). Você precisará dela no próximo passo.


### Passo 4: Conectando o Servidor à Internet via Cloudflare Tunnel (O "Pulo do Gato")

Esta é a etapa que torna seu servidor acessível de qualquer lugar, com segurança e sem configurar o roteador.

**No seu Debian:**

1.  **Instale o `cloudflared`**: Siga a [documentação oficial](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/install-and-setup/installation/) para adicionar o repositório e instalar o pacote.
    ```bash
    # Adiciona a chave GPG do repositório Cloudflare
    sudo mkdir -p --mode=0755 /usr/share/keyrings
    curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare.asc > /dev/null

    # Adiciona o repositório
    echo 'deb [signed-by=/usr/share/keyrings/cloudflare.asc] https://pkg.cloudflare.com/cloudflared trixie main' | sudo tee /etc/apt/sources.list.d/cloudflared.list

    # Instala o cloudflared
    sudo apt update && sudo apt install cloudflared -y
    ```

**No painel da Cloudflare (no navegador do seu computador principal):**

1.  **Adicione seu domínio**: Faça login na Cloudflare, adicione seu domínio e siga as instruções para alterar os servidores DNS do domínio no local onde você o comprou.

2.  **Acesse o Zero Trust**: No painel da Cloudflare, vá em **Zero Trust** > **Networks** > **Tunnels**.
    *   Clique em **Create a tunnel**.
    *   Dê um nome ao túnel (ex: `meu-servidor`). Clique em **Save tunnel**.

3.  **Configure o túnel**: Na próxima tela, escolha o sistema operacional do seu servidor (Debian). Ele mostrará um comando para você executar no servidor.
    ```bash
    sudo cloudflared service install SEU_TOKEN
    ```
    *Copie e execute este comando no terminal do seu Debian.*

4.  **Configure o roteamento (Public Hostnames)**:
    *   Ainda na página de configuração do túnel, vá na aba **Public Hostname** e clique em **Add a public hostname**.
    *   **Subdomain**: Escolha um nome (ex: `brew`, `app` ou `meu-servidor`).
    *   **Domain**: Selecione seu domínio.
    *   **Type**: Selecione **HTTP** (seu aplicativo é web).
    *   **URL**: Digite `localhost:8080` (a porta do seu aplicativo).
    *   Clique em **Save hostname**.
    *   Pronto! O túnel está configurado.

**Teste**: Abra o navegador do seu celular e digite o endereço que você criou: `https://brew.seudominio.com`. Você verá a listagem de arquivos do seu servidor. Está online!


### Passo 5: Acessando pelo Celular Sem Instalar Nada (Browser Rendering)

Para tornar o acesso ainda mais simples e incluir terminais SSH e VNC direto no navegador, o Cloudflare oferece o **Browser Rendering**.

1.  **No painel da Cloudflare**, vá em **Zero Trust** > **Access** > **Applications**.
2.  Clique em **Add an application**.
3.  Selecione **Self-hosted**.
4.  Configure a aplicação:
    *   **Application name**: `Acesso Web do Servidor`
    *   **Application domain**: Defina o mesmo domínio do passo anterior, ex: `brew.seudominio.com`.
    *   **Application visibility**: Pode deixar visível para todos.
5.  Nas **configurações de identidade (Policies)**, crie uma política simples de acesso, exigindo um e-mail ou outros provedores. Isso adiciona uma camada extra de segurança.
6.  **Habilite o Browser Rendering**: Nas configurações avançadas da aplicação, ative a opção **"Browser rendering"**.
7.  Salve a aplicação.

Agora, quando você acessar `https://brew.seudominio.com`, o Cloudflare vai primeiro pedir sua autenticação. Após validar, ele renderizará o conteúdo diretamente no navegador do seu celular, sem necessidade de nenhum aplicativo extra.

## 🤔 E se meu projeto não for um servidor HTTP?

Se você quiser acessar diretamente o terminal do seu servidor Linux, pode configurar um **Public Hostname** com tipo **SSH** e apontar para `localhost:22`. O Cloudflare também oferece suporte nativo para VNC e RDP. Com o **Browser Rendering** habilitado para esses tipos de aplicação, um terminal SSH será aberto diretamente no navegador do seu celular.

---

## 🔒 Considerações de Segurança

1.  **Firewall**: O Debian já vem com um firewall básico. Para maior segurança, considere configurar o `ufw` para permitir apenas SSH (porta 22) e bloquear o resto.
2.  **Senhas Fortes**: Use senhas fortes para seu usuário e para o `root`.
3.  **Mantenha o Sistema Atualizado**: Execute `sudo apt update && sudo apt upgrade` regularmente ou configure atualizações automáticas de segurança.
4.  **Aproveite o Cloudflare Access**: As políticas de acesso do Zero Trust (como exigir login por e-mail) são sua principal defesa. Use-as para todas as aplicações, especialmente o acesso SSH.

---

## 🔧 Solução de Problemas

*   **O servidor web não está acessível**: Verifique se o aplicativo está rodando com `ps aux | grep python`. Confira a porta e se o firewall do Debian a liberou.
*   **O túnel no Cloudflare não está saudável**: Execute `sudo systemctl status cloudflared` no servidor. Verifique os logs com `sudo journalctl -u cloudflared -f`.
*   **Acesso negado ao domínio**: Confirme se os servidores DNS do seu domínio foram alterados para os da Cloudflare e se a propagação já ocorreu (pode levar algumas horas).
