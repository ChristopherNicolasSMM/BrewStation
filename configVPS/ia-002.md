### 🐧 Passo 1: A Escolha do Sistema
O Debian 12 "Minimal" é a melhor base para esse projeto. Aqui estão os detalhes que justificam a escolha e algumas alternativas:
*   **Para hardware antigo:** O Debian 12 já funciona muito bem com apenas **256 MB de RAM** e um processador simples. Sua versão mais enxuta (NetInstall) ocupa pouquíssimo espaço em disco (~600-750 MB) e, após a inicialização, o consumo de memória fica por volta de **120-180 MB**.
*   **Estabilidade como prioridade:** Ideal para servidores, o sistema da Debian é reconhecido pela estabilidade, com atualizações focadas apenas em correções de segurança.
*   **Alternativas:** Se eventualmente a Debian não for a melhor opção, você pode considerar:
    *   **Ubuntu Server 24.04 LTS**: Oferece mais facilidade e uma vasta documentação. É um pouco mais pesado (cerca de 200-280 MB de RAM inicial) e vem com serviços extras como o `snapd`, que podem ser removidos.
    *   **Distribuições ainda mais leves**: Caso o hardware seja extremamente modesto, opções como **Lubuntu** (com interface LXQt) e **antiX** são focadas em desempenho em máquinas antigas.

### 🐍 Passo 2: Instalando e Configurando o Python 3.13
Com o Debian instalado e pronto, o próximo passo é preparar o ambiente com a versão específica do Python que você precisa.
*   **Instalação via `deadsnakes`**: O repositório oficial do Debian 12 tem o Python 3.11. Para instalar a versão 3.13, você precisará usar o repositório `deadsnakes`, que disponibiliza versões mais recentes para distribuições baseadas no Debian/Ubuntu:
    ```bash
    sudo apt update
    sudo apt install software-properties-common
    sudo add-apt-repository ppa:deadsnakes/ppa
    sudo apt update
    sudo apt install python3.13 python3.13-venv python3.13-dev
    ```
*   **Gerenciamento de múltiplas versões**: Após a instalação, você pode gerenciar qual versão do Python será usada por padrão no sistema.
    ```bash
    # Adiciona o Python 3.13 como uma alternativa
    sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.13 1
    # Se houver outras versões, use o comando abaixo para escolher qual será a padrão
    sudo update-alternatives --config python3
    ```

### 🌐 Passo 3: Configurando o Acesso Web (Rede Privada Virtual)
A parte mais importante é expor seu servidor de forma segura e acessível pela internet, sem abrir portas no seu roteador. A solução é usar o Cloudflare Tunnel em conjunto com o recurso de "Browser Rendering" da Cloudflare, que permite acesso direto pelo navegador do celular.
*   **Por que essa abordagem funciona**: Seu computador estabelece uma "ponte segura" (o túnel) para a rede da Cloudflare. Quando você acessa o domínio configurado pelo seu celular, a Cloudflare age como um intermediário e exibe a interface do seu servidor diretamente no navegador, sem precisar de nenhum software extra instalado.
*   **Guia de configuração (Resumido)**: 
    1.  **Prepare o servidor**: Garanta que o **OpenSSH Server** esteja instalado no seu Debian com o comando `sudo apt install openssh-server` e que o serviço esteja ativo.
    2.  **Crie o túnel**: Faça o download e execute o `cloudflared` no seu servidor, seguindo as instruções detalhadas no painel da Cloudflare (Zero Trust > Networks > Tunnels).
    3.  **Configure o acesso pelo navegador**: A "mágica" acontece no painel da Cloudflare. Após criar o túnel, acesse **Zero Trust > Access > Applications** e configure a aplicação. No caminho das configurações, você encontrará a opção **"Browser rendering"**. Ative-a e selecione "SSH" (para acesso ao terminal).
*   **Como acessar**: Com a configuração concluída, você pode abrir o navegador do seu celular, acessar `https://ssh.seudominio.com` (o endereço que você configurou), passar pela autenticação (como um código enviado por e-mail) e terá um terminal do seu servidor disponível diretamente na tela.
