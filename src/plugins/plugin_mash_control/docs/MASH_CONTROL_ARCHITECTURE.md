# Mash Control Plugin
## Arquitetura Técnica

Projeto: BrewStation  
Plugin: mash_control

Objetivo: controlar processos de brassagem com suporte a automação,
integração com hardware e operação manual.

---

# Visão Geral da Arquitetura

O plugin é dividido em 5 camadas principais:

1. Configuração
2. Modelagem de Planta
3. Receita / Rampas
4. Sessão de Execução
5. Integração com Hardware
